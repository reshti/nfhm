====================================================================
منصة «نفهم» التوعوية باضطراب طيف التوحد (جامعة الإمام عبدالرحمن بن فيصل)
دليل الرفع والتثبيت السريع عبر لوحة التحكم cPanel
شعار المنصة: «لأن الفهم بداية التقبل» | هوية المنصة: «مجرد أثر بصمة»
====================================================================

مرحباً بك! هذه الحزمة العالمية المستقلة (Universal Package) مجهزة للعمل
على أي نطاق أو مجلد فرعي (Root / أو /asd/ أو أي مسار متداخل) دون تعديل الكود.

--------------------------------------------------------------------
1. حل مشكلة صفحة "It works!" في cPanel:
--------------------------------------------------------------------
- سبب ظهور "It works!":
  1) عدم بدء تشغيل تطبيق Node.js من أداة "Setup Node.js App".
  2) أو تعيين اسم ملف التشغيل كـ app.js في حين أن المرفوع server.js (أو العكس).
  3) أو وجود RewriteBase / ثابت يوجه طلبات المجلد الفرعي إلى الجذر.

- الحل الجذري المطبق في هذه الحزمة:
  1) تم تضمين كل من app.js و server.js متطابقين ليعمل الخادم بأي اسم تختاره.
  2) ملف .htaccess ذكي يعمل نسبياً في أي مجلد دون فرض جذر.
  3) كود الموقع مبني بمسارات نسبية base: './' مع مكتشف مسارات ذكي.

--------------------------------------------------------------------
2. خطوات التثبيت عبر cPanel (معالج الـ 5 مراحل):
--------------------------------------------------------------------
1) ارفع الحزمة nafham_universal_deployment.zip إلى مجلد موقعك (مثلاً public_html/asd).
2) فك الضغط (Extract).
3) في cPanel -> Setup Node.js App -> اضغط Create Application:
   - Application root: مجلد موقعك (مثال: public_html/asd)
   - Application startup file: server.js أو app.js
   - ثم اضغط Run NPM Install و Restart.
4) افتح المتصفح على رابط موقعك متبوعاً بـ /install
   (مثال: https://yourdomain.com/asd/install)
5) اتبع معالج التثبيت:
   - المرحلة 1: فحص البيئة وصلاحيات الملفات.
   - المرحلة 2: تأكيد الموقع والمسار المكتشف تلقائياً.
   - المرحلة 3: بيانات قاعدة البيانات واختبار الاتصال المباشر.
   - المرحلة 4: حساب المشرف وزرع الجداول التسعة الشاملة.
   - المرحلة 5: تقرير الجاهزية وإطلاق المنصة.

--------------------------------------------------------------------
3. الوصول إلى لوحة تحكم الإدارة (Admin CP):
--------------------------------------------------------------------
- الرابط المباشر: https://yourdomain.com/asd/admincp
- أو عبر الموقع: انقر 5 مرات متتالية على عبارة «مجرد أثر بصمة» في أسفل الصفحة!
- كلمة المرور المؤقتة للتعديل: nafham2026

--------------------------------------------------------------------
4. الجداول التسعة المعتمدة المزروعة في قاعدة البيانات:
--------------------------------------------------------------------
1. nf_users (المستخدمون وحسابات الإدارة المشفرة)
2. nf_certificates (الشهادات والاعتمادات الرسمية)
3. nf_quiz_questions (بنك الأسئلة والتقييمات - 105 أسئلة محكمة)
4. nf_library_topics (موضوعات مكتبة المعرفة باضطراب طيف التوحد)
5. nf_videos (استوديو عروض الفيديو والفيلم الوثائقي)
6. nf_team_members (فريق العمل واللجنة الإشرافية بجامعة الإمام عبدالرحمن)
7. nf_landing_sections (ترتيب وتصميم أقسام صفحات الهبوط)
8. nf_settings (إعدادات الهوية الوطنية والشعار)
9. nf_audit_logs (سجل النشاط والأمان)
